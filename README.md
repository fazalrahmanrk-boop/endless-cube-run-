**ENDLESS CUBE RUN — 3D ADVENTURE GAME**

Create a fast-paced 3D endless runner where a futuristic cube automatically races through an infinite, procedurally generated world. Players control left/right movement, jumping, double-jumping, sliding, dashing, and special abilities.

### Endless Track & Loops

Generate seamless, playable tracks using straight roads, curves, ramps, tunnels, floating platforms, split paths, spirals, 180°/360° loops, wall runs, jump gaps, moving platforms, gravity sections, and secret routes.

**Example:** Road → Ramp → 360° Loop → Wall Run → Jump → Floating Platform → Spiral → Tunnel → New Track.

### Adventure Worlds

Explore **Neon City, Desert Ruins, Frozen World, Jungle Temple, Sky Realm, Cyber Dimension, and Infinite Space**, each featuring unique environments, obstacles, mechanics, and visual effects.

### Progressive Difficulty

Increase speed and challenge as levels advance. Add moving and rotating obstacles, collapsing bridges, lasers, gravity changes, disappearing platforms, harder jumps, and faster loops. High levels become extreme endless challenges.

### XP & Leveling

Earn XP through distance, coins, jumps, perfect landings, dodges, loops, missions, secret routes, and survival time. Unlock new cubes, abilities, trails, effects, worlds, and upgrades.

### Power-Ups

Include **Shield, Magnet, Turbo, Double Coins, Slow Motion, Ghost Mode, and Air Boost.**

### Missions & Combos

Add daily and progression missions for distance, coins, loops, jumps, and survival. Consecutive successful actions create combo multipliers for higher scores and rewards.

### Dynamic Events

Include day/night cycles and changing weather such as rain, snow, fog, storms, sandstorms, and meteor showers. Add occasional giant boss-chase events requiring fast reactions and alternate routes.

### Visuals & Camera

Use polished 3D graphics, dynamic lighting, reflections, shadows, particles, glowing cube trails, and cinematic effects. A smooth third-person camera dynamically follows jumps, loops, turns, and high-speed movement.

**Goal:** Create an infinite adventure where every run is different, challenging, rewarding, and progressively more exciting.
